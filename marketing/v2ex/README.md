# V2EX Post Assets

用于在 V2EX 发布项目分享帖的独立文案素材。

本目录不属于 Skill 功能、能力清单、模板或部署产物；它只服务对外传播。

## 文件说明

| 文件 | 用途 |
| --- | --- |
| `dayu-harness-v2ex-post.md` | V2EX 项目分享帖标题、节点建议和正文。 |
| `dayu-harness-v2ex-flow.svg` | V2EX 正文可引用或上传的 Harness Engineering 流程图。 |

## 维护备注

- 标题和正文突出 Harness Engineering 理念，避免把帖子写成单纯项目广告。
- GitHub 链接保持为完整地址：`https://github.com/kinoward/dayu-harness-skill`。
- 正文保留参考项目和资料链接，方便读者追溯设计来源。
- 如果 V2EX 对 GitHub raw 图片直链展示不稳定，发布时优先手动上传 `assets/readme/dayu-harness-banner.png` 和本目录 SVG，再替换正文中的图片地址。
- 语气保持谦逊、求反馈、欢迎讨论，不把项目描述成成熟通用方案。
