# WeChat Moments Assets

用于朋友圈发布和项目介绍的独立图文素材。

本目录不属于 Skill 功能、能力清单、模板或部署产物；它只服务对外传播。

## 文件说明

| 文件 | 用途 |
| --- | --- |
| `dayu-harness-moments-card.png` | 最终朋友圈竖版配图，尺寸为 `1080x1350`。 |
| `dayu-harness-moments-card.html` | 配图的可编辑排版源，依赖同目录下的人物和二维码素材。 |
| `dayu-harness-moments-copy.md` | 配套朋友圈正文文案。 |
| `dayu-harness-character.png` | 参考 README banner 风格重新生成的 Q 版人物素材。 |
| `dayu-harness-qr-art.png` | 指向 GitHub 仓库的艺术化二维码素材。 |

## 维护备注

- 配图标题使用 `大禹治库.skill`，英文副标题使用 `Dayu Harness Skill`。
- GitHub 链接保持为完整地址：`https://github.com/kinoward/dayu-harness-skill`。
- 如需改图，优先修改 HTML 源后重新导出 PNG，避免中文由图片模型直接生成导致错字。
