## 条目格式

每个排障条目遵循以下严格格式。**TL;DR 必须在最前面**，让 AI 和人类无需读完整文件即可判断是否相关：

```markdown
# <问题简短描述>

**TL;DR**: <一句话 — 症状 + 根因 + 修复>

**日期**: YYYY-MM-DD
**症状**: <观察到的现象，具体的错误信息>
**根因**: <问题的根本原因>
**修复**: <解决方案，含可执行命令>
**预防**: <如何避免再次发生，含可选配置变更>
```

## 新增条目

1. 在对应分类子目录下创建 kebab-case 命名的 `.md` 文件
2. 确保文件以 `## TL;DR` 开头
3. 更新该子目录的 `AGENTS.md`，添加条目索引
4. 同步更新本文件的分类列表（如新增了子目录）
