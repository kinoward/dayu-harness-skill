# exec-plans/AGENTS.md

本目录记录执行计划。活跃计划用于交接当前任务，完成计划用于复盘和追踪已完成工作。

## 目录结构

```
exec-plans/
├── AGENTS.md       # 你正在读
├── active/         # 正在执行或待执行的计划
└── completed/      # 已完成的计划
```

目录结构变化（含目录、文件或能力部署清单变化）时，必须同步更新本区块。

## 子目录

### [active/](active/AGENTS.md)

正在执行或待执行的计划。

### [completed/](completed/AGENTS.md)

已完成的计划。完成后从 `active/` 移入本目录。
