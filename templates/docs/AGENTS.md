# docs/AGENTS.md

本文件是 `docs/` 目录的索引，列出所有子目录入口。AI 应先读取根目录 `AGENTS.md` 了解项目总目标，再读取本文件了解 docs/ 内的结构。

## 工程约束

> AI 读取的规则、经验和决策

### [practices/](practices/AGENTS.md)

工程实践规范。包含 7 个文档：commit 规范、PR 规范、分支与发布、测试策略、开发纪律、AI 协作、Git 语言规范。

### [decisions/](decisions/AGENTS.md)

架构决策记录（ADR）。记录影响项目结构和技术方向的 key 决策。

### [troubleshooting/](troubleshooting/AGENTS.md)

排障知识库。按分类记录排障经验。

### [research/](research/AGENTS.md)

版本化研究院。产品研究、技术选型的版本化管理。

### [scripts/](scripts/)

维护脚本。包含诊断完整性（audit.sh）、smoke test（validate.sh）、差异分析（diff-helper.sh）。
