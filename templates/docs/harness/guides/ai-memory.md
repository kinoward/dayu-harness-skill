# AI 记忆与经验沉淀规约

> 触发时机：产生可复用经验、更新项目知识库、整理会话结论或同步外部记忆时读取。

## 项目记忆权威

项目中的 `AGENTS.md` 与 `docs/` 是项目级长期记忆的单一事实源。外部 Agent memory、LangChain/LangGraph store、向量库或产品内置记忆只能作为运行时检索和上下文召回，不能替代仓库内文档。

外部记忆系统中的有价值内容，必须整理成项目文档并同步对应 `AGENTS.md` 索引后，才视为项目长期记忆。

## 经验沉淀位置

| 经验类型 | 沉淀位置 |
|---------|---------|
| 架构/技术决策 | `docs/design-docs/` |
| 问题排障 | `docs/troubleshooting/` |
| 研究发现 | `docs/references/research/` |
| 约束变更 | `docs/harness/guides/` + AGENTS.md |
| 项目背景和产品上下文 | `docs/product-specs/` |

## 沉淀边界

只沉淀经过归纳的可复用结论，不沉淀：
- 完整对话记录
- 临时假设
- 未确认方案
- 重复推理过程
- 敏感信息

长期目录中的内容必须能被后续 Agent 直接使用：包含背景、结论、适用条件、验证方式和失效条件。

## 生成资料处理

自动生成的草稿、报告或批量整理结果先进入 `docs/generated/`；经确认后再移入长期目录。

不再有效的生成资料应删除或移入 `docs/archive/`，避免后续 Agent 误用旧内容。
