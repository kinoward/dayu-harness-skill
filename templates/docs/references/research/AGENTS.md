# references/research/AGENTS.md

本目录是版本化研究院。产品研究、技术选型、设计原则等内容按版本化目录组织。

## 目录结构

```
research/
├── AGENTS.md                 # 你正在读
└── YYYY-MM-DD-vN/            # 项目新增的研究版本目录
    ├── AGENTS.md             # 该版本研究索引
    └── *.md                  # 研究产出
```

目录结构变化（含目录、文件或能力部署清单变化）时，必须同步更新本区块。

## 目录命名

使用 `YYYY-MM-DD-vN` 格式，如 `2026-04-17-v3`。每个版本目录内包含该阶段的研究产出。
